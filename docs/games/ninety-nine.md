# 九九平台標準規則

九九是「鬥陣來一局」第一款正式實作的牌局，用來驗證私人房間、伺服器權威狀態、回合控制、合法動作判定、出局與勝負判定。

本文件定義平台標準玩法。不同家庭可能有細節差異，但平台會以此版本作為規則引擎與伺服器驗證依據。

## 基本設定

- 使用一副 52 張標準撲克牌，不含鬼牌。
- 支援 2 位以上玩家。
- 每位玩家起手 5 張牌。
- 牌局開始時累積點數為 0。
- 玩家依座位順序輪流出牌。
- 每次出牌後，若牌堆仍有牌，玩家補牌至 5 張。
- 牌局方向預設為順時針。
- 玩家不能讓累積點數小於 0 或超過 99。
- 玩家若輪到自己時沒有任何合法出牌，立即出局。
- 最後剩下的玩家獲勝。

## 一般點數牌

以下牌依牌面數字加入累積點數：

- 2：+2
- 3：+3
- 6：+6
- 7：+7
- 8：+8
- 9：+9

如果出牌後會讓累積點數超過 99，該出牌不合法。

## 特殊牌

### A

A 可由玩家選擇：

- +1
- +11

只能選擇不會超過 99 的選項。

### 4

- 不改變累積點數。
- 反轉牌局方向。

### 5

- 不改變累積點數。
- 出牌玩家必須指定下一位玩家。
- 不能指定自己。
- 不能指定已出局玩家。
- 被指定的玩家成為下一位行動玩家。

### 10

10 可由玩家選擇：

- +10
- -10

只能選擇讓累積點數維持在 0 到 99 之間的選項。

### J

- Pass。
- 不改變累積點數。
- 下一位玩家依目前方向行動。

### Q

Q 可由玩家選擇：

- +20
- -20

只能選擇讓累積點數維持在 0 到 99 之間的選項。

### K

- 將累積點數直接設為 99。
- 不受目前累積點數影響。

## 合法動作判定

規則引擎必須驗證：

- 牌局必須處於 playing 階段。
- 行動玩家必須是目前玩家。
- 玩家不可在出局後行動。
- 玩家只能出自己手上的牌。
- 特殊牌必須帶入必要選項。
- A、10、Q 的選項不可讓累積點數超出 0 到 99。
- 5 必須指定合法目標玩家。
- 非特殊牌不可帶入特殊效果選項。
- 非 5 的牌不可指定目標玩家。

所有合法動作必須由伺服器規則引擎產生或驗證，前端 UI 顯示不可視為權威判定。

## 出局與勝負

- 當玩家輪到自己時，如果手上沒有任何合法出牌，該玩家立即出局。
- 出局玩家不再被回合順序選中。
- 若某次出牌後，後續玩家連續沒有合法動作，系統會依回合方向依序淘汰，直到找到可行動玩家或只剩一位玩家。
- 只剩一位未出局玩家時，牌局進入 finished 階段，該玩家為勝者。

## 實作限制

此規則文件只定義九九規則與純 TypeScript 規則引擎，不包含：

- WebSocket
- Colyseus 或 Socket.IO
- Firebase
- 電腦玩家 AI
- 前端動畫
- 帳號系統
- 遊戲紀錄儲存
