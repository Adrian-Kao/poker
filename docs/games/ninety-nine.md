# 九九平台標準規則

「九九」是鬥陣平台的純娛樂撲克牌遊戲。第一版支援 2 至 6 名玩家，使用一副 52 張標準撲克牌，不使用小丑牌，最後一位尚未出局的玩家獲勝。

## 基本設定

- 每位玩家起始 5 張牌。
- 中央累積點數起始為 0，且必須維持在 0 至 99。
- 遊戲按座位順序進行，預設方向為順時針。
- 玩家出一張牌後，伺服器會將該牌放入棄牌堆，並在抽牌堆仍有牌時補回 5 張。
- 玩家不能看見其他玩家的手牌。
- 前端可以顯示合法提示，但所有合法牌、點數、下一位、出局與勝負都由伺服器驗證。

## 牌面效果

| 牌面 | 平台標準效果 |
|---|---|
| A | 點數加 1 |
| 2 | 點數加 2 |
| 3 | 點數加 3 |
| 4 | 點數不變，遊戲方向反轉 |
| 5 | 點數不變，指定一名仍在遊戲中的其他玩家成為下一位 |
| 6 | 點數加 6 |
| 7 | 點數加 7 |
| 8 | 點數加 8 |
| 9 | 點數加 9 |
| 10 | 玩家選擇 +10 或 -10 |
| J | 點數不變，跳過原本下一位玩家 |
| Q | 玩家選擇 +20 或 -20 |
| K | 中央點數直接變成 99 |

花色不影響效果。

## 點數限制

- 會讓點數低於 0 或超過 99 的選項不合法。
- 目前點數為 5 時，10 只能選擇 +10，不能選擇 -10。
- 目前點數為 90 時，Q 只能選擇 -20，不能選擇 +20。
- K 在任何 0 至 99 的點數下都能合法打出，結果為 99。
- 4、5、J 不改變中央點數，因此在 99 時仍能打出。

## 特殊牌下一位

- 一般數字牌、A、10、Q、K：完成效果後，依目前方向找到下一名仍在遊戲中的玩家。
- 4：先反轉方向，再依新方向找到下一名仍在遊戲中的玩家。兩人遊戲時仍輪到另一名玩家。
- 5：出牌者必須指定一名仍在遊戲中的其他玩家，不能指定自己或已出局玩家。指定後方向不變。
- J：跳過依目前方向原本的下一名仍在遊戲中的玩家，再找到下一名玩家。兩人遊戲時會跳過對手，因此輪回出牌者。

## 出局與勝利

- 若輪到某玩家時，手中沒有任何合法出牌方式，該玩家立即出局。
- 出局玩家的剩餘手牌會放入棄牌堆。
- 出局玩家不再參與後續回合。
- 所有尋找下一位的邏輯都會跳過已出局玩家。
- 遊戲繼續直到只剩一名未出局玩家，該玩家獲勝。

## 抽牌堆回收

每次合法出牌後：

1. 打出的牌放入棄牌堆。
2. 玩家從抽牌堆補牌，盡量回到 5 張。
3. 若抽牌堆為空，伺服器會將棄牌堆中除了最近一張公開牌之外的牌重新洗牌，成為新抽牌堆。
4. 最近一張公開牌繼續保留在桌面。
5. 所有洗牌使用可注入亂數來源。
6. 不得產生或遺失牌；若沒有足夠牌補回 5 張，玩家保留現有手牌繼續遊戲。

## 電腦玩家

九九支援電腦補位。電腦玩家分為簡單、普通、困難三種難度，決策由伺服器執行，且只能使用一般玩家可見資訊，不得讀取真人玩家的隱藏手牌。

## 逾時

每回合由伺服器建立 30 秒期限。真人逾時時，伺服器會重新取得合法動作並代為打出一張合法牌；若沒有合法動作，該玩家出局。前端只顯示倒數，不自行判定逾時。
